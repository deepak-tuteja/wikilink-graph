# Saved views

Whatever's currently hidden or shown — filtered types, active tags, hub toggles — can be saved as a
named view and recalled later from the toolbar's view picker, stored in `localStorage` alongside the
[[theming|theme]] choice. Handy for a large wiki where you keep coming back to the same filtered
slice (e.g. "just the `guide` pages") instead of rebuilding the filter state by hand each time.

Delete a saved view from the same picker; there's no limit on how many you keep.
