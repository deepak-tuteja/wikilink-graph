# Search

The search box in the toolbar filters as you type and shows a dropdown of matching pages by label;
picking one opens it directly. Matches are also highlighted on the graph itself if you dismiss the
dropdown without picking one, so you can see where a term lives before committing to open it.

Useful once a wiki grows past what you can visually scan — see [[getting-started]] for where the
search box sits, and [[keyboard-nav|keyboard navigation]] for browsing once you've landed somewhere.
