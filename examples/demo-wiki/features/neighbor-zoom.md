# Neighbor-focus zoom

Click a node (or land on one via [[keyboard-nav|keyboard navigation]]) and the view smoothly
zoom-to-fits that node plus its direct neighbors, instead of leaving you to hunt for context at
whatever zoom level you happened to be at. It re-triggers on every new selection, so browsing by
repeatedly clicking through a [[force-directed-layout|graph]] stays readable no matter how zoomed in
or out the previous view was.
