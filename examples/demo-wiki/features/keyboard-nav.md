# Keyboard navigation

**Status** active

With a node selected, arrow keys cycle through its direct neighbors one at a time — wrapping
around, sorted for a stable order — without leaving the graph. **Enter** opens the reader for
whichever neighbor is currently highlighted; **Esc** backs off the in-progress cycle first, and a
second **Esc** clears the selection entirely.

It's a keyboard-only path through the same connections a mouse would follow by hovering and
clicking — see [[getting-started]] for the mouse-driven version of the same idea.
