# Glossary

A few terms used across this wiki:

- **Ghost node** — a link target with no matching page. See [[ghost-nodes]].
- **Slug** — a page's lowercased filename (no extension); how `[[wikilinks]]` resolve to a node.
- **Type** — a node's color-and-cluster category. A nested page's type is its top-level folder
  (`concepts`, `guides`, `features`, `reference`); a root-level page like this one gets its own
  filename stem as its type instead of collapsing into one shared bucket, so `glossary`,
  `INDEX`, etc. each cluster and color separately. See [[type-clustering]].

This page has no `tags:` and isn't excluded by default, so it's a plain visible node — a small
illustration of a root-level page's own type in action.
