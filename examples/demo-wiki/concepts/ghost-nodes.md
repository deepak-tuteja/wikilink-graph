# Ghost nodes

**Status** active

A **ghost node** is a page that something links to but that doesn't exist yet. wikilink-graph still draws
it — dashed instead of filled — so gaps in your wiki are visible at a glance.

For example, this page links to [[backlinks]], which has no file. That link becomes a ghost node in
the graph: a standing invitation to write the missing page.

Ghosts disappear the moment you create the file. Related: [[wikilinks]], [[writing-pages]].
